# Ravenloft Music

Свой синхронизированный музыкальный плеер для Owlbear Rodeo, под кампанию
«Проклятие Страда». Написан с нуля (ни строчки чужого кода из DJinni),
использует только официальный `@owlbear-rodeo/sdk` — синхронизацию между
твоим экраном и экранами игроков делает сам Owlbear Rodeo, поэтому
**никакого своего сервера/бэкенда не нужно**. Это просто статичные файлы
(HTML/JS/CSS), которые нужно один раз где-то бесплатно разместить.

Плейлист (16 папок, 50 стримов, 52 трека) уже встроен в `data.js` — тот же
самый, что в `RAVENLOFT_MUSIC.djinni`, только исправленные ссылки и без
затухания, которое роняло DJinni.

## Как это работает

- **Мастер** (роль GM в Owlbear Rodeo) видит кнопки play/pause и ползунки
  громкости, **игроки** видят только текущее состояние и свою личную
  громкость — это разграничение работает только в интерфейсе, поэтому не
  полагайся на него как на защиту от читинга, но для своей группы этого
  достаточно.
- Значок ✎ в шапке (виден только мастеру) включает **режим редактирования**:
  можно добавить новый трек в любую папку (название, иконка-эмодзи, ссылка,
  «зацикленный»/«одноразовый»), создать целиком новую папку, переименовать
  или скрыть/удалить любой трек и папку — без моего участия и без
  редактирования `data.js`. Всё это сразу видно у всех, кто сейчас в
  комнате (хранится в `room metadata` Owlbear Rodeo, отдельно от встроенного
  плейлиста). У комнаты общий лимит 16 КБ на метаданные всех расширений —
  на десятки-сотни добавленных треков хватит с запасом, но не на
  безграничную библиотеку.
- Состояние (какой трек играет, с какой позиции, какая громкость) хранится
  в `room metadata` Owlbear Rodeo — это значит, что если игрок перезайдёт
  в комнату посреди сессии, он сразу услышит то же самое, с той же позиции.
- Звуки из Soundpad — одноразовые: мастер жмёт кнопку, все, кто сейчас в
  комнате, слышат его один раз (через `broadcast`, ничего не сохраняется).
- Громкость на каждый трек **всегда** ограничивается числом от 0 до 1 перед
  тем как попасть в `audio.volume` — именно это чинит краш, который убивал
  DJinni (`IndexSizeError` на отрицательной громкости).
- Ссылки Dropbox автоматически переводятся с `dl=0` (это HTML-страница
  предпросмотра, не поток) на `dl=1` (прямой файл) — это тоже частая причина
  тишины/ошибок у подобных плееров.

## Шаг 1 — разместить файлы (бесплатно, 5–15 минут)

Нужен просто публичный HTTPS-адрес, по которому будет доступен
`manifest.json`. Два варианта:

### Вариант A — Netlify Drop (самый быстрый, вообще без регистрации)

1. Открой https://app.netlify.com/drop
2. Перетащи туда всю эту папку целиком (`manifest.json`, `index.html`,
   `app.js`, `data.js`, `icon.svg`).
3. Netlify тут же даст адрес вида `https://random-name-123.netlify.app`.
4. Твой манифест: `https://random-name-123.netlify.app/manifest.json`.

Минус: без регистрации адрес может быть временным/случайным. Если хочешь
навсегда — зарегистрируйся там же (бесплатно), тогда можно закрепить сайт
за аккаунтом и не бояться, что он исчезнет.

### Вариант B — GitHub Pages (то, что ты сам предложил — «локальный конфиг
+ опенсорс на гитхаб»)

1. Создай новый репозиторий на github.com (можно приватный).
2. Залей туда все файлы из этой папки (через веб-интерфейс — кнопка
   «Add file → Upload files», или `git push`, как удобнее).
3. Settings → Pages → Source: **Deploy from a branch**, ветка `main`,
   папка `/ (root)` → Save.
4. Через пару минут сайт появится по адресу
   `https://<твой-логин>.github.io/<имя-репозитория>/`.
5. Твой манифест:
   `https://<твой-логин>.github.io/<имя-репозитория>/manifest.json`.

Это постоянный адрес, привязанный к твоему аккаунту — вариант понадёжнее.

## Шаг 2 — установить в Owlbear Rodeo

Точно так же, как сейчас установлен DJinni:

1. В Owlbear Rodeo → Extensions (иконка расширений) → Install extension →
   вставить URL твоего `manifest.json` из шага 1.
2. Готово — появится кнопка «Ravenloft Music» рядом с остальными
   расширениями.
3. Игрокам ничего дополнительно ставить не нужно — расширение появится у
   них само, как только оно добавлено в комнату (так же, как сейчас
   работает с DJinni).

## Если что-то не заработает

Открой консоль браузера (F12 → Console) прямо как в прошлый раз с DJinni,
пришли мне скриншот или текст ошибок — я разберусь и поправлю код.
